# Cách Đơn Giản Nhất Để Preview QML UI

## ✅ KHÔNG CẦN CÀI ĐẶT GÌ THÊM!

Qt Creator đã có sẵn QML Preview, bạn chỉ cần:

### Bước 1: Mở Qt Creator
```bash
qtcreator
```

### Bước 2: Mở file QML preview
1. Trong Qt Creator: **File** → **Open File** (hoặc `Ctrl+O`)
2. Điều hướng đến: `/home/khoi/NetworkProgramming/client/qml_preview/`
3. Chọn một trong các file:
   - `preview_MenuStart.qml`
   - `preview_LoginPage.qml`
   - `preview_SignUpPage.qml`
   - `preview_MenuMain.qml`
   - `preview_GameScreen.qml`
   - `preview_ChangePasswordPage.qml`

### Bước 3: Preview ngay lập tức
Sau khi file mở, bạn có 3 cách:

**Cách 1: QML Preview (Nhanh nhất)**
- Nhấn `Ctrl+Shift+P`
- Hoặc click chuột phải vào file → **"Preview"**

**Cách 2: Design Mode**
- Nhấn `Alt+Shift+D`
- Hoặc click tab **"Design"** ở dưới editor

**Cách 3: Run**
- Nhấn `Ctrl+R`
- Hoặc click nút Run (mũi tên xanh)

---

## 🎯 Preview Tất Cả Các Màn Hình

1. Mở Qt Creator
2. Mở từng file preview một
3. Nhấn `Ctrl+Shift+P` để preview
4. Đóng preview và mở file tiếp theo

---

## 💡 Tips

- **Live Editing**: Thay đổi code trong editor sẽ tự động cập nhật preview
- **Properties Panel**: Trong Design mode, bạn có thể thay đổi properties trực tiếp
- **Component Tree**: Xem cấu trúc component trong Navigator panel
- **Multiple Previews**: Có thể mở nhiều file cùng lúc để so sánh

---

## ❌ Nếu Qt Creator chưa có

Nếu bạn chưa cài Qt Creator:
```bash
# Ubuntu/Debian
sudo apt-get install qtcreator

# Hoặc download từ qt.io
```

**Nhưng nếu đã có Qt Creator rồi thì không cần cài thêm gì cả!**
